# Living Surface TLDR — 2026-09-22 EDT

**Thesis:** Backend systems feel absent until bound to **UI ack + world dress + ambient echo**. Aliveness ≠ content count; it’s **3–5 concurrent diegetic signals** with clear cause→effect.

## Patterns that work
- **One fact → three surfaces** (meter + sash/door + gossip line)
- **Diegetic boards / delayed icons** (Witcher) over map-first checklists
- **Local memory > global meters** (RDR2 honor + bartender recall)
- **Remembrance tokens** after bosses (FromSoft)
- **Schedule spectacle** — job props/animations, not off-screen ticks
- **Archetype ambient pools** (GTA) before unique bios for everyone
- **Nested “who is this?”** cards/tooltips (CK3/Imperator)
- **Street-Cred-style unlocks** that gate cars/gigs/discounts (Cyberpunk)

## Benchmark cheat-sheet
| Game | Signature surface |
|---|---|
| Witcher 3 | Notice boards, irreversible flags, companion echo |
| RDR2 | Routines, witness memory, newspaper/camp |
| Cyberpunk | Street Cred → tangible unlocks (thin true factions) |
| Elden Ring | Remembrance / world mutation on key kills |
| Palworld | Pals labor + ride + base raids |
| GTA V | Archetype reaction dialogue + wanted stars |
| CK3/Imperator | Nested tooltips, event portraits, crisis alerts |
| Skyrim | Radiant re-offers, titles/housecarls, hidden disposition |

## MVP density
**Alive hub:** ≥2 working NPCs + ambient line ~20–40s + faction dress + one reactive greeting + board/vendor that reflects state.  
**Sparse:** ≤1 signal. **Overloaded:** 9+ competing alerts.

## Wire first (inert stack)
1. Quest accept→complete + world proof  
2. Kill→spoils→gossip/witness  
3. Hub hour schedules (job motion)  
4. Faction sash / door / greeting  
5. Diegetic board  
Then: vendor mirror → raid telegraph/remembrance → mount ritual → companion banter → crafting→worn gear.

## Anti-patterns
Fake boards · unread logs · HUD +0 world · one-shot demos · icon density as life · overpromised “city remembers you” · radiant without voice · sim without spectacle · boss as HP-only · companion as mute pet.
