# Open-world research brief (Concordia) — 2026-09-21

## Starfield lessons
- **Scale ≠ density.** Critics + ex-Bethesda (Nesmith, Purkeypile): thin planets / repeated POIs / menu travel kill Skyrim-style road distraction.
- **Keep:** authored city moments (Neon). Hybrid tiles OK only if curated hard.
- **Avoid:** identical outposts, map-ping every POI, commute-as-content, dead city outskirts, generic multi-path that rewards the boring route (Cyberpunk GDC 2023).
- Concordia already has ONE plane + SoftEnter — dense Hub + dressed spokes, not empty ring km.

## Process map (lore → ship)
Lore bible / tonal refs → concept (key art, biome boards, weenies) → map/heightfield blockout → greybox POIs + traversal tests → art dress → systems (schedules, wildlife, weather) → quest/NPC authoring → encounter/loot → playtest heatmaps → polish/audio → QA → ship.
- **Bethesda:** Creation Kit; place ownership; Starfield = hand tiles + hubs inside proc shells (“space quilts”) — prefer fewer deep worlds.
- **RDR2:** narrative first; handmade + curated tools; ambient schedules; horse as traversal toy; “everywhere you look, something drawing you.”
- **BOTW/TOTK:** gravity (POI pull) + triangle rule (reveal/obscure); vertical stack + traversal toys.
- **Witcher 3:** quest content sizes the world, not reverse; all placement handcrafted.
- **Art pipeline:** lore → concept (push color) → blockout → dress → in-engine early (Skyrim/Tsushima). Concordia CX plates = concepts; mats done; prefabs+bind next.

## Worth traveling (actionable → Concordia)

14. Exclusive path rewards (Cyberpunk)

## Player expectation checklist
Named NPC schedules + gossip reflecting world state · faction branding readable · towns with function + skyline · wilderness discoverable · combat camps not clones · contextual loot · **one “only here” beat per major region**.
